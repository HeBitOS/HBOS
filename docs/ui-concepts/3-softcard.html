卡片优先 · 现代桌面

以卡片为基本容器：大圆角（10–14px）、柔和多层阴影、克制的 1px 亮边、充足留白， 强调色从 Breeze 蓝换成靛紫 indigo/violet。视觉目标接近当代 Web 应用与 macOS Big Sur —— 让 HBOS 的 13 个应用共享同一套「浮起来的表面」语言，而不是 13 种各自为政的平面配色。

/* hbos/gui/theme.h — 全部应用只读这一个结构体，禁止硬编码颜色 */ typedef struct gui_theme_t { gui_color_t bg, surface, surface2, surface3; /* 画布与三层卡片 */ gui_color_t line, line2; /* 1px 分隔线 / 亮边 */ gui_color_t fg, fg2, dim; /* 三级文字 */ gui_color_t accent, accent_fg, accent_hover; /* 靛紫强调色 */ gui_color_t ok, warn, err; /* 语义色 */ gui_color_t sel; /* 选中行底色（accent 低透明度）*/ int radius, radius_small; /* 14 / 10 */ uint8_t shadow_alpha; /* 0..255，多层阴影统一强度 */ } gui_theme_t; /* 应用侧：只引用令牌，不写死颜色字面量 */ gui_fill_round_rect(x, y, w, h, T->radius, T->surface); /* 卡片 */ gui_fill_round_rect(rx, ry, rw, rh, T->radius_small, T->sel); /* 选中行 */ gui_text(x, y, name, T->fg); gui_text(x, y, meta, T->dim); gui_round_rect_border(x, y, w, h, T->radius, T->line, 1);
◆ 实现代价提示：本方案的柔和多层阴影与大圆角在合成阶段更贵。内核态软件合成器没有 GPU 加速时， 圆角需要逐行裁剪 + alpha 混合，多层阴影要么预烘焙成九宫格位图（推荐：每种半径/强度一张，缓存复用）， 要么退化为单层半透明描边。建议 gui_theme_t 里保留 radius 与 shadow_alpha， 让低配机器把 radius 拉到 4、shadow_alpha 拉到 0，视觉不崩但开销显著下降。
