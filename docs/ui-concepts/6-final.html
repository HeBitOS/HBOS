主题包：外部文件加载

/themes/<name>.theme 文件格式

# HBOS 主题包 v1
name = Breeze Card Dark
based_on = dark
accent = #3daee9
accent_hover = #4db8f0
bg = #191c1f
surface = #24282c
surface2 = #2b3034
surface3 = #33393f
fg = #eff0f1
fg2 = #bdc3c7
dim = #7f8c8d
ok = #27ae60
warn = #f67400
err = #da4453
radius = 10
radius_small = 7
shadow = soft

加载与回退规则

  • 启动扫描 /themes/*.theme，按文件名列出可用主题
  • 只覆盖声明了的键，其余继承 based_on 基主题
  • 未知键忽略并告警；非法颜色回退到基主题值
  • 所有键缺失时仍能启动（内置 dark/light 兜底）
  • 切换主题写入 /startup.cfg 跨重启保留
  • 主题只影响令牌，不改变布局与控件尺寸
为什么用纯文本：解析器只需 ~150 行 C，无依赖、易手改； 损坏的主题文件不会让系统起不来。

  ok, warn, err, sel,
  radius, radius_small, shadow_alpha
}
