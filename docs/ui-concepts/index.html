HBOS 统一 UI 风格方案

第一步：确定视觉语言。已定案 1.1（Breeze Card）——5 种候选保留作对照，均可切换深色 / 浅色。

定案 · 1.1
Breeze Card ★
骨架取自 01，观感向 03 靠拢 · 含主题包格式

保留 Breeze 的语义色与克制（迁移成本最低），升级为中圆角 + 分层柔影 + 卡片化。 额外包含强调色替换与 /themes/*.theme 外部主题包格式、加载回退规则。这是将落地的方案。

★ 定案深/浅色主题包强调色可换
方案 01
Breeze Continuity
延续现状 · 平面 · 蓝色强调

与现有 cyber_neon_* 配色（KDE Breeze 取向）一脉相承，改动成本最低。平面化、细边框、克制阴影。

低迁移成本平面蓝色系
方案 02
Neon Terminal
终端优先 · 等宽 · 单色强调

放大 HBOS 的极客气质：等宽字体、高信息密度、单色荧光强调。深色为默认，浅色是"高亮纸"。适合终端类应用为主的系统。

高密度等宽低开销
方案 03
Soft Card
圆角卡片 · 层次阴影 · 现代

卡片化布局 + 柔和阴影 + 大圆角，观感最"当代"。对模糊/阴影绘制有要求，需评估内核渲染开销。

现代感卡片含阴影
方案 04
Nordic Calm
低饱和 · 低对比 · 护眼

北极色系，弱化色相冲突，长时间使用最舒适。强调色克制，适合办公/阅读类场景。

护眼低饱和无障碍
方案 05
Brutalist
硬边 · 高对比 · 零装饰

直角、粗描边、无渐变无阴影。渲染开销最低，辨识度最高，适合低配/嵌入式场景。

零开销高对比辨识度
如何选择：每种方案都给出了同一组组件（按钮 / 输入框 / 列表 / 标签页 / 对话框 / 工具栏 / 状态栏） 与同两个应用界面（文件管理器、系统设置）的深色+浅色对照，可直接横向比较。
选定的方案将作为 gui_theme_t 设计令牌落地，所有系统应用改为只引用令牌、不再硬编码颜色。
