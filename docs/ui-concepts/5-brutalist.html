方案 05 · Brutalist

Raw / Render-Cheap 模式 MODE DARK

原始、硬边、零装饰：0 圆角、2px 实心描边、无渐变、无阴影、无透明、最大对比度，配少量高饱和原色。 结构靠边框直接说出来，而不是靠投影暗示。所有绘制都是「实心矩形 + 描边」，对软件合成器与低端 / 嵌入式目标最友好。

gui_theme_t · C 结构体

/* hbos/gui/theme.h — 全部应用共用这一份令牌 */
typedef struct {
    gui_color_t bg, surface, surface2, surface3;
    gui_color_t line, line2;
    gui_color_t fg, fg2, dim;
    gui_color_t accent, accent_fg, accent_hover;
    gui_color_t ok, warn, err, sel;
    int         radius, radius_small;  /* brutalist: 0 / 0 */
    uint8_t     shadow_alpha;         /* brutalist: 0   */
} gui_theme_t;

static const gui_theme_t theme_dark_brutal = {
    .bg = 0x000000, .surface = 0x0B0B0B,
    .surface2 = 0x151515, .surface3 = 0x222222,
    .line = 0xFFFFFF, .line2 = 0x8C8C8C,
    .fg = 0xFFFFFF, .fg2 = 0xCFCFCF, .dim = 0x8A8A8A,
    .accent = 0x0057FF, .accent_fg = 0xFFFFFF,
    .accent_hover = 0x2F77FF,
    .ok = 0x00C853, .warn = 0xFFE600, .err = 0xFF2D20,
    .sel = 0x0057FF,
    .radius = 0, .radius_small = 0, .shadow_alpha = 0
};

应用只引用令牌 · Usage

/* 一个应用一行即可换肤：不出现任何硬编码颜色 */
const gui_theme_t *T = gui_theme();

gui_fill (g, x, y, w, h,      T->surface);
gui_frame(g, x, y, w, h, 2, T->line);      /* 2px 实心描边 = 结构 */
gui_text (g, x+10, y+8, lbl, T->fg);
gui_fill (g, x, y, w, h,      T->sel);        /* 选中：实心色块 */

/* ✗ 反面教材：绕过令牌，主题切换立刻失效 */
// gui_fill(g, x, y, w, h, 0xFF1B1E20);
渲染成本 radius = 0 且 shadow_alpha = 0： 没有圆角反锯齿、没有阴影模糊、没有半透明图层，每个控件都是整数矩形填充 + 2px 描边。 这是 5 个方案中最便宜的一种——软件合成器只需 memcpy 式行填充， 低端机与嵌入式目标也能跑满帧率，代价是必须靠边框把层级说清楚。
